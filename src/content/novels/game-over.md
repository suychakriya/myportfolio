# Game over

ទីង!
វាគឺជាសំឡេងនៃសារមួយពីមនុស្សម្នាក់ដែលធ្វើអោយក្មេងស្រីញញឹមដូចមនុស្សឆ្កួតបន្ទាប់ពីដឹងថាអ្នកណាឆាតមកនាង។ គេគឺជាក្មេងប្រុសម្នាក់ដែលត្រូវជាមិត្តភក្ដិរបស់នាង។
ក្មេងប្រុស៖ 'ហេ, ទំនេរអត់?'
ក្មេងស្រី៖ 'មានការអី?'
ក្មេងប្រុស៖ ‘នាងប្រាប់ខ្ញុំឱ្យទៅសារភាពប្រាប់ក្រាស់ខ្ញុំអី ហើយឥឡូវនេះនាងបដិសេធហើយ។ '

3 នាទីគ្មានការឆ្លើយតបពីក្មេងស្រី
ក្មេងស្រី៖ 'ឯងចង់លេងហ្គេមមួយមែនទេ?'
ក្មេងប្រុស៖ 'ហ្គេមអី?'
ក្មេងស្រី៖ ‘វាជាការភ្នាល់។ ប្រសិនបើឯងឈ្នះ ខ្ញុំនឹងធ្វើរឿងមួយសម្រាប់ឯង។ ម៉េចដែរ?’
ក្មេងប្រុស៖ 'សម្រាប់ខ្ញុំ? រឿងអីគេនឹង?'
ក្មេងស្រី៖ 'ប្រសិនបើឯងឈ្នះ ឯងនឹងដឹង'
ក្មេងប្រុស៖ ‘គិតថាខ្ញុំខ្លាចមែន? អូខេលេងក៏លេង!'
ក្មេងស្រី៖ 'ល្អ! លក្ខខណ្ខគឺសាមញ្ញទេ។ ប្រសិនបើឯងអាចធ្វើឱ្យក្រាស់របស់ឯងក្លាយជាសង្សាររបស់ឯងក្នុងរយៈមួយសប្តាហ៍ ឯងនឹងឈ្នះ។ '
ក្មេងប្រុស៖ ‘ហេ? នាងដឹងរួចហើយថា នាងទើបនឹងបដិសេធខ្ញុំ។មិនយុត្តិធម៌សោះ! '
ក្មេងស្រី៖ 'ហាហា! ច្បាប់គឺច្បាប់ ហើយការភ្នាល់គឺភ្នាល់។ ប្រសិនបើឯងមិនលេង បានន័យថាចាញ់ '
ក្មេងប្រុស៖ 'អូខេយល់ព្រម! អ្នកណាខ្លាច! '
បន្ទាប់ពីនោះមួយសប្តាហ៍ នៅពេលយប់ មានសារមួយលេចឡើងនៅលើអេក្រង់ទូរសព្ទម្តងទៀត។
ក្មេងប្រុស៖ 'ហេ! មិនគួរឲ្យេជឿំមែន! នាងឥឡូវយល់ព្រមធ្វើជាមិត្តស្រីរបស់ខ្ញុំហើយ "
ក្មេងស្រី៖ "អូ! ល្អណាស់! ចឹងឯងឈ្នះហើយ។ '
ក្មេងប្រុស៖ 'ល្អ! ឥឡូវនេះប្រាប់បាននៅថា រឿងអីដែលនាងធ្វើសម្រាប់ខ្ញុំ?> ។
ក្មេងស្រី៖ ហាហា! កុំបារម្ភ! ខ្ញុំនឹងចាត់ការវា។ ថ្ងៃស្អែកវានឹងរួចរាល់ហើយ។ '
ក្មេងប្រុស៖ 'ចម្លែក! តែអីក៏អីទៅ ព្រោះខ្ញុំសប្បាយចិត្តខ្លាំងណាស់ដែលខ្ញុំព្យាយាមអស់ពីសមត្ថភាពតាមញ៉ែក្រាស់របស់ខ្ញុំរហូតក្លាយជាមិត្តស្រីរបស់ខ្ញុំ។ អូខេ! សុបិន្តល្អណា! '
ក្មេងស្រី៖ 'អូខេ! រាត្រីសួស្តី។ Game Over!'
ក្នុងពេលនោះដែរ ទឹកភ្នែកចុងក្រោយជាមួយស្នាមញញឹមនៃការឈីចាប់របស់ក្មេងស្រីនោះបានធ្លាក់ចុះមកដិតលើអេក្រង់ទូរស័ព្ទខណៈដែលនាងចុចប៊ូតុងផ្ញើរពាក្យ ‘Game Over’។ នាងបានធ្វើតាមការសន្យានៅក្នុងយប់នោះ គឺនាងលុបចោលនូវសេចក្ដីស្រលាញ់របស់នាងដែលមានទៅលើក្មេងប្រុសនោះ ព្រោះវាគ្មានប្រយោជន៏អីទៀតទេក្នុងពេលដែលគេបាននៅជិតមនុស្សដែលគេស្រលាញ់ហើយ។ ហ្គេមនេះចប់ហើយ ហើយនាងក៏ជាអ្នកចាញ់ដែរ តែយ៉ាងណាក៏ នាងជាអ្នកធ្វើឲ្យមនុស្សនាងស្រលាញ់បានសមបំណងដែរ។
